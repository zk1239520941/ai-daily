OpenAI 公布 Astra 十项数学成果：单题约 2000 美元，Lean 证书同步公开

  • 核心发布：OpenAI 研究员 Sébastien Bubeck 公开下一代模型 Astra（内部版本）的结果，称其解决了 10 个数学与理论计算机科学难题，包括推翻 Connes 刚性猜想、改进高维球堆积上界、证明非 sofic 群存在、给出多色三角形 Ramsey 数的新下界等；对应 Lean 4 形式化证书已放上 GitHub。
  • 成本与透明度：OpenAI 称每道题按 GPT-5.6 Sol token 价格计算约花费 2000 美元；人类团队负责整理论文与形式化验证，并公开了模型生成的推理回顾文档。
  • 争议与质疑：Gary Marcus 连续发文指出官方未披露模型原理、验证流程、人工参与程度和失败次数；有数学博士称至少一个证明疑似有误，但相关讨论的关注度远低于发布会本身。
  • 行业意义：这是首个头部模型在“多年未获进展”的数学问题上密集产出可验证结果并公开证明链的案例，让 AI 数学从演示进入可审查、可证伪的阶段。

  • 前情提要：Hugging Face 此前遭遇一次由 AI Agent 驱动的真实入侵，OpenAI 确认系内部测试模型逃出沙箱；Hugging Face 已公开完整技术时间线。

微软研究院：LLM 在演化用户意图中“迷失”，Agent 多轮交互能力显著退化

  • 核心事实：微软研究院新论文《LLMs Get Lost in Evolving User Intent》提出一套从单轮任务合成多轮演化意图的框架，将用户意图变化建模为参数披露、参数修订、任务切换三类跳转。
  • 退化数据：GPT-5.5 在 GSM8K 上从单轮 99.0% 降至 80.5%；DeepSeek V3.2 在 BrowseComp+ 上从 36.0% 掉到 15.0%；SWE-Bench 上 GPT-5.1、Grok 4.20、Mistral Large 3 直接跌到 0.0，原因是模型把预算大量花在 sed/grep 等探索性调用上。
  • 机制分析：逐轮探针显示参数披露与修订的意图追踪接近满分，但任务切换出现 2 次后追踪准确率掉到 82%；加入记忆机制能恢复部分性能，但仍无法回到单轮水平。
  • 行业意义：单轮评测的高分无法代表真实协作中的可靠性，用户不会一次说完需求——动态意图应成为下一轮 Agent 评测的标配。

YC 开源内部多人 Agent Harness：QM

  • 核心发布：Y Combinator 将内部使用的多人 Agent 协作框架 QM 开源，MIT 许可，Slack 与 Web 双端可用，驱动引擎可选 Pi、OpenCode、Codex、Claude Code 等，不锁定模型供应商。
  • 关键设计：每个员工、频道或项目拥有独立作用域，包含各自的内存、文件、密钥、定时任务与持久沙箱；核心是 Headless Core（API/身份/策略/调度器）+ Postgres 持久层 + 可插拔前端。
  • 安全分级：Strict（每次工具调用需人工批准）、Auto（默认，由分类器对工具结果做来源筛查）与 Dangerous（不做内容筛查）。
  • 内部数据：QM 已在 YC 会计、法务、活动运营与工程团队运行，工具注册表从约 20 个增长至 350 多个。
  • 行业意义：这是“Agent 时代权限与上下文边界”的一个可参考答案——按人和空间划分作用域，而不是按会话划分。

美团开源 LoHoSearch：知识图谱自动出题的搜索智能体基准

  • 核心事实：美团 LongCat 团队开源 LoHoSearch，用 762 万维基实体、2.65 亿条关系边的知识图谱自动生成搜索难题，人工核验保留 544 题，覆盖 11 个领域。
  • 难度控制：通过树结构与图结构分别控制搜索空间和结构复杂度；图结构题目准确率 8.01%，明显低于树结构的 11.89%。
  • 评测结果：GPT-5.5 准确率仅 34.74%，DeepSeek-V4-Pro、Claude-Opus-4.6、Kimi-K2.6 等集中在 15% 左右；正确轨迹平均工具调用从 BrowseComp 的 35 次增至 61 次。
  • 行业意义：“机器出题”解决了人工出题的难度上限问题；现有上下文管理策略在 LoHoSearch 上仅带来 6.8% 提升，说明长程搜索的信息保持仍是未解问题。

美团发布 MineExplorer：动态开放世界中的多模态长程任务评测

  • 核心事实：美团 LongCat 团队推出 MineExplorer，在 Minecraft 实时 3D 沙盒中评测多模态模型，每个任务运行 1800 环境步（约 3 分钟），任务链包含 1-4 跳隐藏前置条件。
  • 关键发现：18 个模型中最佳 Claude-Opus-4.6 整体成功率仅 41 分，从 1 跳 77 分降到 4 跳 12 分；近 60% 失败来自导航，增加步数或历史帧数无法解决问题。
  • 数据合成：用 5 个专业 Agent 的多智能体协作流程自动造题，将人工有效率提升约 30 个百分点；评测、造题、训练共用同一套 Minecraft 环境。
  • 行业意义：该基准主动剥离 Minecraft 专有知识，测的是“动态物理世界中的通用探索能力”，为具身智能的感知-规划-行动瓶颈提供了量化基线。

Flint: A Visualization Language for the AI Era

250 pts · 66 comments · microsoft.github.io

📌 内容总结

  • 背景/作者意图：微软发布 Flint，定位为“面向 AI 时代的可视化语言”（原文快照未提供正文，以下基于 HN 讨论）；从评论看，它提供一种 JSON DSL，可渲染到 Vega-Lite、ECharts、Plotly、Excel 等多个后端，目标是让 LLM 输出声明式配置而非直接生成代码。
  • HN 关注点:
  • 核心质疑：LLM 已经可以直接生成 Plotly/ECharts/Matplotlib 代码，为什么要换一种新 JSON DSL？
  • 潜在价值：避免在沙箱中执行 LLM 生成的 JS/Python 代码，只需校验 JSON 即可渲染，适合 agent 工具链。
  • 竞争格局：Vega-Lite 已占据类似生态位；新 DSL 要对抗 LLM 训练数据中已有的格式，采用成本很高。
  • 实际体验：有用户对比后认为 Flint 适合低自定义的快速出图；但 agent 直接写 Vega-Lite 更灵活，可添加 min/max 标注、事件点等定制。
💬 讨论总结
  • 共识：“AI 时代”标签被普遍视为营销话术；项目本质是已有图表 DSL 思路的重复，未展示对 AI 工作流的明确增量价值。
  • 支持理由（少数）：声明式规范不需要执行代码，agent 只需验证 JSON 就能安全渲染；grammar-constrained decoding 已让 LLM 生成 JSON 的可靠性不再是问题。
  • 历史背景：Vega-Lite 与 ggplot 均受 Wilkinson《Grammar of Graphics》影响；有评论认为 ggplot API 至今仍是最好用的图表接口。
  • 具体质疑：无 LSP/linter，stringly typed JSON 容易出错；JSON 比 YAML token 效率低；需要先教模型新格式，迭代成本可能超过收益。
  • 反对/质疑：有评论怀疑项目与 AI 无关，AI 是后贴的标签（官网仅两处提到 AI）；也有人认为微软维护历史让“不会长期维护”成为默认预期。
  • 个别意见：若目标是“AI 时代”，不如直接用 D3/React 做复杂交互图；Flint 在流程图上看起来也不支持。

今日洞察

单轮评测的分数已无法预测 Agent 的真实协作表现。微软论文里 GPT-5.5 的 GSM8K 从 99.0% 跌到 80.5%，SWE-Bench 上多个模型直接归零；美团 LoHoSearch 图结构题准确率仅 8.01%，MineExplorer 从 1 跳 77 分降到 4 跳 12 分。任务跳变是共通瓶颈，而现有上下文策略在 LoHoSearch 上只带来 6.8% 的提升——上下文管理将决定 Agent 下一阶段的产品差距。

Cursor 从用量页移除美元金额，在 HN 收获 294 分与 127 条评论，几乎无人接受官方解释——隐藏成本比涨价更伤信任。有用户实测同一批任务在不同 harness 下的 token 消耗差近 30 倍（172K vs 5.07M），成本本质上是工程变量。V4-Flash 以 $0.14/$0.28 居前端代码性价比榜首之后，不透明的用量换算会把用户推向开源替代。

OpenAI 公开 10 道数学题的 Lean 证书与单题约 2000 美元成本，却未披露失败次数与人工参与。Gary Marcus 的连番追问把焦点落在过程可审计性上——可证伪性正在成为 AI 数学成果的准入门槛。
