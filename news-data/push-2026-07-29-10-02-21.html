Anthropic：Claude Mythos 发现加密算法 HAWK 与 AES 的弱点

  • 核心发布：Anthropic 今日公布新研究，其 Claude Mythos Preview 模型帮助研究人员发现了两个密码学算法中的弱点：HAWK（一种签名方案）和 AES（高级加密标准）。相关论文及模型思维链已公开。
  • 配套基准：Anthropic 与苏黎世联邦理工学院、特拉维夫大学和海法大学合作构建了 CryptanalysisBench，用于系统评估 LLM 的密码分析能力，论文已发表于 arXiv。
  • 行业意义：这是首次有公开记录显示前沿 AI 模型能主动发现经典加密算法的弱点，标志着 AI 在密码学领域的角色从“辅助分析”转向“独立发现”，对后量子密码迁移和安全评估具有深远影响。

MCP 协议重大升级：2026-07-28 规范发布，协议转为无状态

  • 核心发布：MCP（Model Context Protocol）发布了自推出以来最大规模的修订版 2026-07-28 规范。核心变化包括：协议转为无状态（移除 initialize 握手机制和 session 依赖），可在普通 HTTP 基础设施上扩展；新增标准化头部（Mcp-Method、Mcp-Name）使中间件无需解析 body 即可路由；引入扩展框架与 TTL 缓存控制；弃用 Roots、Sampling 和 Logging 功能。
  • AWS 同步支持：AWS 今日正式宣布 Amazon Bedrock AgentCore Gateway 支持 2026-07-28 规范，用户只需调用 UpdateGateway 添加版本号即可切换，且支持多版本并存。
  • 行业意义：这是 MCP 从初创协议走向企业级标准的关键一步。无状态化消除了粘性会话带来的扩展瓶颈，标准 HTTP 头使基础设施组件（负载均衡器、API 网关）无需侵入式解析即可参与治理，这大幅降低了 MCP 在生产环境中的部署门槛。

OpenAI 发布两款新转录模型：GPT-Transcribe 与 GPT-Live-Transcribe

  • 核心发布：OpenAI 今日在 API 中推出两款新转录模型：GPT-Live-Transcribe 专为低延迟实时转录设计，GPT-Transcribe 面向异步音频文件与批量任务。两款模型均支持上下文感知，能处理口音、专业术语和背景噪声。
  • 关键数据：在 22 种语言的 Common Voice 上，GPT-Transcribe 的转录错误率为 19.27%，远低于 Whisper（whisper-1）的 40.37%。在 9 种语言的真实世界录音基准上，错误率为 8.98% vs 15.21%。上下文感知 ASR 的语义准确率从 41.6% 提升至 45.2%。
  • 行业意义：这是 OpenAI 首次在语音领域推出非 Whisper 自研模型，且性能大幅超越 Whisper，表明转录基础模型的代际切换已经开始。对于实时语音交互和多语言语音应用，错误率减半意味着用户体验的质变。

Kimi K3 Architecture Overview and Notes

314 pts · 43 comments · sebastianraschka.com

📌 内容总结

  • Sebastian Raschka 对 Moonshot AI 开源的 Kimi K3 (2.8T MoE) 架构进行了分析。K3 是其 2025 年 Kimi Linear (48B) 的规模化生产版本，引入了 LatentMoE（压缩线性层，类似 Nemotron 3 Ultra）和 Attention Residuals（跨层残差连接）。
  • HN 关注点:
  • 完全去除 RoPE: K3 在所有层使用 NoPE (No Positional Embeddings)，而非其他前沿模型的“局部 RoPE + 全局 NoPE”混合方案。评论指出其依赖 Kimi Delta Attention (KDA) 的 RNN 特性提供位置信息。
  • 效率优先: 多数组件（MLA, LatentMoE, KDA）皆为效率优化的变体，K3 是唯一一个将 Attention Residuals 规模化到前沿水平的模型。
  • Benchmark 水平: 与 Opus、Fable 等同属一个梯队，被部分用户视为 “Claude 的合法威胁”。
💬 讨论总结
  • NoPE 实现机制的技术论证: 社区普遍理解 KDA（一种类似 Gated DeltaNet 的 RNN）通过其固有的时序结构提供了位置信息，因此模型可以不依赖 RoPE。有评论指出，RoPE 本身有一定破坏性，移除它反而有利。
  • LatentMoE 的工程细节: LatentMoE 压缩了各层间传输的数据，对路由器的选择提出了更严格的要求。K3 通过更平衡的专家选择策略提升了性能。
  • 对中国 AI 创新的争议: 部分评论反对西方实验室关于“Kimi 仅靠蒸馏”的说法，认为 K3 架构引入了确实的新方法（如 NoPE、LatentMoE、Attention Residuals）。也有观点认为两者并不互斥，蒸馏与创新可以并存。
  • KV-cache 的实际副作用: 一位用户实测发现，由于 KDA 的实现方式，KV-cache 采用固定增量块（如 1024 tokens），导致最长可达 1023 tokens 的额外缓存未命中开销。
  • 开源代码的可复现性: 用户询问从论文到实现的“最后一公里”是否受阻。回复指出核心模型架构可复现，但完全复现训练（包括数据集和训练管线）基本不可能。

Discovering Cryptographic Weaknesses with Claude

182 pts · 125 comments · anthropic.com

📌 内容总结

  • Anthropic 宣布其 Claude Mythos Preview 模型发现了密码算法的数学弱点：一是改进了对后量子签名方案 HAWK 的攻击（将有效密钥强度减半）；二是改进了对缩减轮数 AES-128 的攻击（速度提升 200-800 倍）。
  • HN 关注点:
  • 实际影响与局限: 两个攻击均不威胁当前生产系统。HAWK 尚未标准化，AES 攻击仅针对 7 轮（共 10 轮），且属于选择明文攻击模式（在实践中已过时）。
  • 成本与可复现性: 每次攻击的 API 成本约 10 万美元。攻击发现过程存在大量随机性，当前无法保证稳定复现。
  • 验证瓶颈: 尽管模型发现迅速，但人类验证其正确性耗时更长（例如 AES 攻击验证花费了数百小时）。
💬 讨论总结
  • 攻击的学术价值与商业宣传的差距: 社区明确指出，这些是“预期的”攻击（HAWK 的自动化寻找此前已知的理论弱点；AES 攻击仅改进了已有的中间相遇攻击），而非发现未知的根本弱点。
  • 多智能体协作的随机性: 评论质疑攻击发现是否依赖于搜索的随机性，而非真正的协作创新。有观点认为“智能体协作”可能只是 LLM 在模仿剧情套路（一人否决，另一人坚持），而非逻辑必然。
  • 对后量子密码学的谨慎态度: 用户普遍对完全依赖 PQC 不信任，主张“混合加密”（PQC + 经典算法），认为在发现攻击后不应仓促弃用经典组件。
  • AI 作为研究工具的潜力与副作用: 社区认可 AI 在“搜索解空间”和“连接已有研究”上的价值。但担忧 AI 会“硬化”问题——部分问题被 AI 解决后，人类可能因“连 AI 都解决不了”而放弃尝试，产生寒蝉效应。
  • 安全研究界的适应难题: 多位评论者指出，AI 发现漏洞的速度已远超人类验证和修复的能力，这对现有的漏洞分类、验证和修复流程构成了真实挑战。

今日洞察

AI 从“辅助分析”进入“独立发现”阶段，但验证瓶颈开始倒挂。 Anthropic 今日披露的 Claude Mythos 发现 HAWK 和 AES 弱点是重要信号——不是攻击本身（两个攻击均不威胁当前生产系统），而是 AI 首次在密码学领域主动完成“假设生成→搜索验证→结论产出”的闭环。然而 HN 讨论中暴露了两个真实约束：每次攻击 API 成本约 10 万美元且无法稳定复现，人类验证耗时数百小时远超模型发现时间。这意味着 AI 发现漏洞的速度已经超过人类验证和修复的能力，安全研究界的流程适应将成为新瓶颈。

MCP 无状态化是 Agent 基础设施从“原型”走向“生产”的关键转折。 2026-07-28 规范移除了 initialize 握手机制和 session 依赖，将协议直接架在普通 HTTP 上。这消除的是过去困扰 MCP 部署的最大工程痛点：粘性会话导致无法水平扩展、基础设施组件（负载均衡器、API 网关）无法参与治理。AWS 同日支持是验证——当云厂商愿意在原生产品中嵌入该协议，说明 MCP 已从 Claude 生态内的自定义协议成长为可被企业基础设施接纳的开放标准。后续影响是 Agent 间通信的成本结构将从“维护 session 状态”转向“HTTP 请求+缓存控制”。

转录基础模型的代际切换已经开始。 OpenAI 的 GPT-Transcribe 在 22 种语言上错误率 19.27%（Whisper 40.37%），这不是增量改进而是减半。关键细节是模型首次脱离 Whisper 架构——OpenAI 在语音领域第一次使用自研非 Whisper 模型。对于实时语音交互、多语言翻译、客服场景，错误率减半带来的不是“体验更好”，而是“功能从不可用变为可用”。同时该模型支持上下文感知 ASR，语义准确率从 41.6% 提升至 45.2%，意味着它开始理解说话内容而非仅仅识别音素。

Agent 治理工具链正在成为与模型能力同等重要的基础设施。 Microsoft 今日开源的 agent-governance-toolkit（5.2k stars）和 Google 在 Managed Agents 中引入环境钩子、Token 预算上限，共同指向同一个趋势：当 Agent 从聊天界面走向后台持续运行和多工具调用，企业部署的核心矛盾已经从“能不能做”转为“如何保证不做不该做的事”。两个项目的设计都在强调“策略执行在应用代码层完成，不依赖 prompt 安全”，这是对近期多起 Agent 越狱/滥用事件的直接回应。
